# **App Name**: Real Estate Hub

## Core Features:

- Property Listing: Display a list of real estate properties with key information like price, location, and number of bedrooms.
- Advanced Filtering: Implement a comprehensive filtering system allowing users to narrow down properties based on criteria such as price range, location, property type, number of bedrooms/bathrooms, and other amenities.
- CRUD Management (Admin): Admin users can create, read, update, and delete property listings through a dedicated content management interface.
- User Roles and Permissions: User authentication and authorization system to differentiate between regular users and admin users, controlling access to CRUD functionalities.

## Style Guidelines:

- Primary color: Teal (#008080) to convey trust and stability.
- Secondary color: Light gray (#F2F2F2) for backgrounds and neutral elements.
- Accent color: Orange (#FFA500) for call-to-action buttons and highlights.
- Body font: 'Roboto' (sans-serif) for a clean and readable experience.
- Headline font: 'Montserrat' (sans-serif) for a modern and bold look.
- Use simple, outlined icons related to real estate (house, map marker, bedroom, bathroom) for a professional and intuitive interface.
- Clean and spacious layout with clear separation of elements to avoid clutter. Prioritize high-quality property images.
- Subtle animations for transitions and loading states to enhance the user experience.
